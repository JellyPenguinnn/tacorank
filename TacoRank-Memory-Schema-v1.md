# TacoRank Memory Schema v1

Schema version: `1.0`

The executable schema is `src/tacorank/schemas.py`. This document describes the
durable event format and authority rules; it must be changed with the executable
models and fixtures in one integration change.

## Authorities

TacoRank has exactly three authorities:

1. `contract/COMPETITION.md` and `PROTECTED_PATHS.md` for human rules;
2. `runs/<run_id>/events.jsonl` for dynamic evidence; and
3. Git for code bytes, diffs, ancestry, and the best pointer.

All status, lesson, summary, graph, and context Markdown files are derived artifacts.

## Encoding

- UTF-8 JSON Lines, exactly one compact canonical JSON object per complete line.
- Object keys are lexicographically sorted; NaN and infinity are forbidden.
- Sequence starts at one and is contiguous.
- `event_id` is `evt_<sequence padded to six digits>`.
- Complete lines are immutable. Only bytes after the last newline may be removed as
  an incomplete crash tail.
- Append holds an exclusive file lock, validates the complete prefix, writes one line,
  flushes, and calls `fsync` before acknowledgement.

## Envelope

Every line contains:

```text
schema_version: "1.0"
event_id: evt_000001
seq: integer >= 1
timestamp: timezone-aware UTC timestamp
run_id: stable run identifier
event_type: EventType
idempotency_key: unique immutable-input key
causation_event_id: earlier event ID or null
payload: event-type-discriminated payload
artifact_refs: unique ArtifactRef values collected from the payload
resource_delta: action-local ResourceDelta
prev_event_hash: lowercase SHA-256, zero hash for genesis
event_hash: SHA-256 of canonical envelope with event_hash omitted
```

The idempotency key format is:

```text
run_id:experiment_id:stage:attempt:sha256(canonical immutable input)
```

A repeated key returns the already-acknowledged event at the orchestrator boundary;
it never repeats an expensive external action.

## Event types and payloads

| Event type | Payload authority |
| --- | --- |
| `run.started` | Frozen config, contract/protected hashes, budgets and seeds |
| `contract.verified` | Metric names, allowed commands and artifact roots |
| `baseline.verified` | Official baseline parity result |
| `context.created` | Immutable role context, sources, exclusions and artifact hash |
| `planner.recommended` | Advisory non-proposal output |
| `experiment.proposed` | Validated `ExperimentSpec` |
| `patch.created` | `PatchCandidate` identity and artifacts |
| `patch.checked` | Gate A checks and receipt |
| `execution.started` | Legal `RunRequest` |
| `execution.finished` | `RunResult` and measured resources |
| `recovery.decided` | Person 4 `RecoveryDecision` |
| `output.checked` | Gate B `OutputCheckResult` |
| `evaluation.completed` | Person 5 metrics and trust assessment |
| `experiment.decided` | Promotion/terminal recommendation and eligibility |
| `best.updated` | Trusted validation-best projection change |
| `lesson.recorded` | Canonical lesson candidate assigned a harness ID |
| `lesson.status_changed` | Later active/superseded/stale/rejected state |
| `manual.intervention` | Sole source of intervention count |
| `run.stopped` | Frozen deterministic stop reason |
| `final.selected` | Cleanly reproduced best candidate |
| `submission.checked` | Final submission artifact and checks |

The exact field definitions and cross-field invariants are generated by the Pydantic
models. Unknown fields are rejected at every adapter boundary.

## ArtifactRef

```text
artifact_id: stable ID
kind: diff | trajectory | context | log | checkpoint | predictions |
      metrics | verification_receipt | submission | report | other
path: normalized repository-relative POSIX path
sha256: 64 lowercase hexadecimal characters
size_bytes: integer >= 0
content_type: string or null
```

Validation rejects absolute and parent paths, path normalization changes, symlinks,
unapproved roots, missing bytes, size mismatches, and hash mismatches.

## Resource accounting

Every adapter result supplies one `ResourceDelta`. Provider-measured and estimated
tokens are never mixed. GPU-hours are:

```text
sum(gpu_time_ms * gpu_count) / 3_600_000
```

Agent wall-clock is elapsed time from `run.started` to the current or stopped event,
not a sum of action durations. Only `manual.intervention` events increment the autonomy
intervention count.

## Replay invariants

Replay validates, in order:

1. UTF-8 and strict event schema;
2. contiguous sequence and matching event ID;
3. one run ID and unique idempotency keys;
4. causal references to earlier events;
5. the complete SHA-256 chain;
6. every legal state transition; and
7. decision-bearing artifact bytes when an artifact store is supplied.

The reducer then rebuilds `RunState`, experiment nodes, active lessons, best identity,
convergence inputs, and resource totals. No mutable projection is consulted.

## Change policy

Backward-compatible v1 additions require defaults and fixture coverage. Removing,
renaming, or changing the meaning of a field requires a new schema version and an
explicit decision about old-ledger replay. Adapter-local event/enumeration variants are
not allowed.
